V1.1 是这条 UI 线的**成品归档**：扁平化表面、纯色背景、实例轨道与启动坞都在这个包里。

- **显示名**：`Theresia V1.1`

## 怎么用

拖进启动器「设置 → 开发者选项 → 前端（第三方 UI）」的虚线框即可安装；
或者「导入前端包…」选中后在列表里点「使用」→「重启前端」。

## 源码在哪

V1.1 的完整源码在 git 历史里，不在当前工作区：

```powershell
# 看 V1.1 最后那个提交

# 需要改动时，把源码取出来

```
